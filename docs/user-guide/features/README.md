# 功能

TwipsyBot 的核心功能围绕 Misskey 中的三类动作展开：接收消息、发布内容、订阅实时事件。

| 页面 | 内容 |
| --- | --- |
| [提及、聊天与访问控制](interactions.md) | 普通回复、上下文、限流和用户名单 |
| [自动发帖与图片生成](posting.md) | 定时发帖、手动发帖、可见性和 `/img` |
| [时间线与天线](timelines.md) | 四类时间线、天线和插件依赖 |
| [聊天管理命令](admin-commands.md) | `^` 管理命令和 `/` 操作命令 |

建议先让提及和聊天稳定工作，再逐步启用自动发帖和时间线插件。
