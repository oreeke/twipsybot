## Iincho 插件

没错我是委員長，每隔一段时间汇总本地时间线帖子，发布脱敏违规概览，并把热点和违规帖子 ID 私信给管理员（打小报告）

### 启用

在主配置中设置 `bot.timeline.local: true`<br>
复制并调整 `config.yaml.example`，将 `enabled` 设为 `true`<br>
重启机器人

周期从插件启动时开始计算。有效帖子不足、趋势生成或内容审核失败、发布失败时跳过本周期，不补发

`admin_ids` 填写接收小报告的 Misskey 用户 ID，可配置多个。发现疑似违规样本时，Iincho 会私信发送原帖 ID；单个管理员发送失败不影响其他管理员或摘要发布。留空则不发送提醒

Iincho 使用固定容量均匀抽样，不保存帖子内容，不补采离线数据，不处理图片。通用生成模型只总结热点趋势；文本风险由 OpenAI `omni-moderation-latest` 批量审核，并归并为骚扰攻击、仇恨歧视、色情内容、暴力威胁、自伤风险和违法活动六类。自定义 OpenAI 兼容端点需要支持 `/moderations`

风险结果只表示模型对抽样帖子的分类信号，不代表人工裁定或全量审核；疑似违规原文和用户身份不会写入成帖
